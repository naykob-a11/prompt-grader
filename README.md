# Prompt Grader · เกรดสีจากพร้อมต์

เว็บแอปปรับโทนภาพถ่ายจาก **พร้อมต์แบบโครงสร้าง** เลือกพร้อมต์จากคลัง เขียนเอง หรือแนบไฟล์ `.sgp.txt` → ตัวอ่านในเครื่องแปลงเป็นค่าปรับ → เครื่องยนต์ในเบราว์เซอร์ปรับสี แสง ความคม และบรรยากาศ โดย **ไม่สร้างภาพใหม่** ใบหน้า วัตถุ และองค์ประกอบจึงคงเดิมทุกพิกเซล

- ไม่มีเซิร์ฟเวอร์ ไม่ใช้ API key **ไม่มีค่าใช้จ่ายต่อการใช้งาน** โฮสต์ฟรีแบบ static
- ใช้งานออฟไลน์ได้ ภาพและพร้อมต์ไม่ออกจากเครื่อง
- พร้อมต์เขียนอิสระ (เช่นพร้อมต์ภาษาอังกฤษยาว ๆ) แปลงได้ด้วยปุ่ม "คัดลอกคำสั่งสำหรับแชต Claude" แล้ววางคำตอบกลับ

ตัวอย่างพร้อมต์แบบโครงสร้าง:

```text
# ชื่อ: เช้าสดใส
ความสว่าง: สว่างขึ้น เล็กน้อย
เงา: ยก ปานกลาง (+30)
สีไฮไลต์: ครีม เล็กน้อย
ม่วง: อิ่ม เพิ่ม ปานกลาง
ความคม: เล็กน้อย
[หมายเหตุ]
ใช้กับภาพบุคคลในร่ม
```

## สถานะ

ชุดนี้คือ **ชุดเริ่มต้นสำหรับสร้างด้วย Claude Code** ประกอบด้วยสเปก, skills, ข้อมูลตั้งต้น, ต้นแบบเครื่องยนต์ และตัวอ่านพร้อมต์อ้างอิงที่ผ่าน test แล้ว โค้ดแอปจะถูกสร้างตาม `docs/15-claude-code-playbook.md`

## เริ่มต้นใช้งานกับ Claude Code

```bash
cd prompt-grader
git init && git add . && git commit -m "chore: project kit"
node --test reference/sgp-reference.test.mjs   # ตรวจตัวอ่านอ้างอิง (Node ≥ 20) — ควรผ่าน 18/18
claude                                         # เปิด Claude Code แล้ววางคำสั่งระยะ P0 จาก playbook
```

## Skills ที่เรียกใช้เองได้

| คำสั่ง | ทำอะไร |
|---|---|
| `/add-preset <พร้อมต์>` | แปลงพร้อมต์ใหม่เป็นพรีเซ็ตในตัว + ไฟล์ `.sgp.txt` |
| `/add-vocabulary "<คำ>" = <ความหมาย>` | สอนตัวอ่านให้รู้จักคำใหม่ |
| `/add-parameter <ชื่อ — คำอธิบาย>` | เพิ่มแถบเลื่อนใหม่ครบทุกชั้น |
| `/verify` | ตรวจงานก่อน commit |
| `/release [patch\|minor\|major]` | ปล่อยเวอร์ชัน |

skill `grading-engine`, `structured-prompt`, `thai-ui` ถูกโหลดอัตโนมัติเมื่องานตรงกับคำอธิบาย
