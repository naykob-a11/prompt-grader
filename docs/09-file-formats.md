# 09 · รูปแบบไฟล์และการแนบพร้อมต์

ระบบไม่มีเซิร์ฟเวอร์ API ทุกอย่างเข้า-ออกผ่านไฟล์และคลิปบอร์ดของผู้ใช้

## 1. ไฟล์พร้อมต์แบบโครงสร้าง `.sgp.txt`

| เรื่อง | ข้อกำหนด |
|---|---|
| รูปแบบ | ตาม `06-structured-prompt-format.md` |
| นามสกุลที่รับ | `.sgp.txt` (แนะนำ), `.txt`, `.md` |
| การเข้ารหัส | UTF-8 (มี/ไม่มี BOM); ไฟล์ที่ถอดรหัส UTF-8 ไม่ได้ → แจ้งให้บันทึกใหม่เป็น UTF-8 |
| ขนาดสูงสุด | 64 KB ต่อไฟล์, 2,000 บรรทัด |
| ชื่อไฟล์ส่งออก | `<ชื่อพรีเซ็ต>.sgp.txt` (ตัดอักขระต้องห้ามของระบบไฟล์) |

### วิธีแนบ
1. ปุ่ม **"แนบไฟล์พร้อมต์"** ในตัวแก้ไข (เลือกได้หลายไฟล์)
2. **ลากไฟล์ `.sgp.txt` มาวาง** บนแผงคลังพร้อมต์ (ลากภาพมาวางบนเวทีภาพ — แยกเป้าหมายกันชัด)
3. **วางข้อความ** ในช่องพร้อมต์ (รวมคำตอบที่คัดลอกจากแชต Claude)

### พฤติกรรมเมื่อแนบ
- ไฟล์เดียว → เปิดในตัวแก้ไข อ่านค่าทันที แสดงคำเตือน ยังไม่บันทึกจนกว่าผู้ใช้กดบันทึก
- หลายไฟล์ → นำเข้าคลังทั้งหมด (`source: 'import'`) แล้วสรุป "นำเข้า n พร้อมต์, คำเตือน m รายการ"
- ชื่อพรีเซ็ตมาจาก `# ชื่อ:` ถ้าไม่มี ใช้ชื่อไฟล์

## 2. ไฟล์คลังพร้อมต์ `.json`

ใช้สำรองหรือย้ายทั้งคลัง รายละเอียดฟิลด์ใน `07-data-model-storage.md` ข้อ 3 ทุกรายการเก็บทั้ง `params` (ตัวเลข) และ `prompt` (ข้อความโครงสร้าง) — เมื่อนำเข้า **ใช้ `params` เป็นหลัก**; ถ้าไม่มี `params` ให้อ่านจาก `prompt`

## 3. ส่งออกพรีเซ็ตเดียว

| ตัวเลือก | ผลลัพธ์ |
|---|---|
| ไฟล์พร้อมต์ (`.sgp.txt`) | `serialize()` ของค่าปัจจุบัน + หมายเหตุ — คนอ่านได้ แก้ได้ แนบกลับได้ |
| คัดลอกเป็นข้อความ | ข้อความเดียวกันลงคลิปบอร์ด สำหรับวางในแชตหรือเอกสาร |

## 4. คลิปบอร์ด

| การกระทำ | ข้อมูล |
|---|---|
| คัดลอกคำสั่งสำหรับแชต Claude | `seed/sgp-bridge-instruction.md` โดยแทน `{{FREE_PROMPT}}` ด้วยข้อความในช่อง "พร้อมต์อิสระ" |
| วางคำตอบจากแชต | ข้อความโครงสร้าง (รั้วโค้ดถูกข้ามอัตโนมัติ) |
| วางภาพ | ไปที่เวทีภาพ เมื่อโฟกัสไม่ได้อยู่ในช่องข้อความ |
