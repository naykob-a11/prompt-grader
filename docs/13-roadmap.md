# 13 · Roadmap หลัง MVP

เรียงตามคุณค่าต่อผู้ใช้เทียบกับความยาก

| ลำดับ | ฟีเจอร์ | คุณค่า | แนวทางเทคนิค | ความยาก |
|---|---|---|---|---|
| R0 | **(ทางเลือก) แปลงพร้อมต์อิสระอัตโนมัติ** | ไม่ต้องคัดลอกไปแชตเอง | โมดูลเสริมที่ปิดเป็นค่าเริ่มต้น: เรียกโมเดลภาษา (เช่น Claude API ผ่าน backend ของผู้ใช้ หรือโมเดลในเครื่องผ่าน WebGPU) ให้ **ตอบเป็นข้อความ SGP** แล้วผ่านตัวอ่านเดิม — ตัวอ่านและรูปแบบไม่ต้องเปลี่ยน | กลาง |
| R1 | **Batch** ใช้พรีเซ็ตเดียวกับหลายภาพ, ส่งออกเป็น zip | โทนชุดเดียวกันทั้งอัลบั้ม | คิวงานใน Worker, `fflate` ทำ zip, ควบคุมหน่วยความจำทีละภาพ | กลาง |
| R2 | **ส่งออก LUT `.cube`** (เฉพาะส่วนที่ไม่ขึ้นกับตำแหน่ง/ข้างเคียง) | ใช้พรีเซ็ตใน Lightroom, Resolve, CapCut | สุ่มลูกบาศก์ 33³ ผ่าน grade() โดยปิด haze/vignette/grain/detail | ต่ำ |
| R3 | **Mask เฉพาะพื้นที่**: ผิว, ท้องฟ้า, ตัวบุคคล | ทำพร้อมต์พอร์ตเทรตได้ครบ (ฉากหลังเป็นกลาง, คมเฉพาะตา) | segmentation บนเครื่อง (MediaPipe Image Segmenter / ONNX Runtime Web); พารามิเตอร์ต่อ mask; schema แบบ `layers[]` | สูง |
| R4 | **คำสั่งสำหรับแชตแบบปรับต่อ** | "อุ่นขึ้นนิด หมอกน้อยลง" | คำสั่งแชตที่แนบพร้อมต์ SGP ปัจจุบัน ขอให้แก้เฉพาะบรรทัดที่เกี่ยวข้อง | ต่ำ |
| R5 | **ภาพย่อพรีเซ็ต** บนภาพปัจจุบัน | เลือกพรีเซ็ตเร็วขึ้น | เรนเดอร์ 160 px ต่อพรีเซ็ตด้วย GPU | ต่ำ |
| R6 | **ซิงก์คลาวด์** + แชร์ลิงก์คลัง | ทีมใช้คลังร่วมกัน | Supabase (Auth + Postgres + RLS) หรือ Cloudflare D1; รักษา local-first ด้วยคิวซิงก์ | สูง |
| R7 | **จับคู่โทนจากภาพอ้างอิง** | "ทำให้เหมือนภาพนี้" | เทียบสถิติสี (ค่าเฉลี่ย/ส่วนเบี่ยงเบนใน Lab, histogram) ของสองภาพแล้วคำนวณค่าพารามิเตอร์ในเครื่อง → เขียนออกเป็น SGP | กลาง |
| R8 | **Curves** RGB/Luma แบบจุดควบคุม | ควบคุมโทนละเอียด | LUT 1D 256 จุดใน texture | กลาง |
| R9 | ปรับรัศมี detail ตามสเกลพรีวิว | พรีวิวความคมตรงกับไฟล์จริง | radius = fullW/previewW, sampling แบบ bilinear | ต่ำ |
| R10 | แอปเดสก์ท็อป (Tauri) | ทำงานกับโฟลเดอร์ภาพโดยตรง | ห่อ apps/web, ใช้ fs ของ Tauri | กลาง |

| R11 | **ภาษาพร้อมต์เพิ่ม** | ผู้ใช้ภาษาอื่น | เพิ่มคำใน `sgp-vocabulary.json` (ไม่แก้โค้ด) | ต่ำ |
