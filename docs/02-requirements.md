# 02 · ความต้องการของระบบ (Requirements)

รหัสความต้องการ `FR-xx` (เชิงหน้าที่) และ `NFR-xx` (ไม่ใช่เชิงหน้าที่) ใช้อ้างอิงใน commit, test และ PR ได้

## 1. ขอบเขต

**อยู่ในขอบเขต:** ปรับสี แสง โทน คอนทราสต์ ความคม จุดรบกวน หมอก เกรน และขอบมืด ทั้งภาพ จากพร้อมต์ข้อความหรือแถบเลื่อน

**นอกขอบเขต (MVP):** สร้างหรือลบวัตถุ, รีทัชผิวเฉพาะจุด, ครอปหรือหมุนภาพ, แก้ไฟล์ RAW, การปรับเฉพาะพื้นที่ (mask) — mask อยู่ใน roadmap

## 3. ความต้องการที่ไม่ใช่เชิงหน้าที่

| รหัส | ความต้องการ | วิธีวัด |
|---|---|---|
| NFR-01 | พรีวิวตอบสนอง ≥ 30 fps ที่พรีวิว 2048 px บนแล็ปท็อปที่มี GPU ในตัว | benchmark ใน e2e |
| NFR-02 | ส่งออกภาพ 24 MP ภายใน 5 วินาทีด้วย GPU | benchmark |
| NFR-03 | ภาพ พร้อมต์ และคลัง ไม่ถูกส่งออกจากเครื่อง | e2e ตรวจว่าไม่มี request ออกนอก origin |
| NFR-04 | ใช้งานได้บนมือถือกว้าง 360 px ไม่มีการเลื่อนแนวนอนของหน้า | Playwright mobile viewport |
| NFR-05 | ธีมสว่าง/มืดตามระบบ | ภาพหน้าจอทั้งสองธีม |
| NFR-06 | การเข้าถึง: ใช้คีย์บอร์ดได้ทุกส่วน, contrast ≥ 4.5:1 | Lighthouse ≥ 95 |
| NFR-07 | ใช้งานออฟไลน์ได้ทุกฟีเจอร์ | PWA test (ปิดเครือข่ายแล้วใช้ครบทุกขั้น) |
| NFR-08 | ข้อความ UI เป็นภาษาไทยทั้งหมด รองรับการเพิ่มภาษาอังกฤษ | i18n key ครบ |
| NFR-09 | เครื่องยนต์ทำซ้ำได้: อินพุตเดียวกัน → ผลเดียวกันทุกครั้ง | golden tests |
| NFR-10 | ไม่มีค่าใช้จ่ายต่อการใช้งาน: แอปไม่เรียกบริการภายนอกใด ๆ | ตรวจ network ใน e2e = 0 request ภายนอก |
| NFR-11 | อ่านพร้อมต์ 2,000 บรรทัดได้ภายใน 20 ms | benchmark ของตัวอ่าน |

## 4. เกณฑ์ยอมรับ MVP

1. ผู้ใช้ใหม่เปิดภาพ เลือกพรีเซ็ต และบันทึกภาพได้ภายใน 1 นาทีโดยไม่ต้องอ่านคู่มือ
2. ไฟล์พร้อมต์ทั้ง 6 ไฟล์ใน `seed/structured-prompts/` แนบแล้วได้ค่าตรงกับ `seed/builtin-presets.json` ทุกพารามิเตอร์ และไม่มีคำเตือน
3. ภาพที่ส่งออกมีขนาดเท่าต้นฉบับ และเมื่อใช้ค่าเป็นกลาง ภาพเหมือนต้นฉบับ (ต่างไม่เกินผลของการ re-encode JPEG)
