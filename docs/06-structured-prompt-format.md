# 06 · รูปแบบพร้อมต์แบบโครงสร้าง (Structured Grading Prompt · SGP)

> แทนการเรียก API: ผู้ใช้เขียนหรือแนบพร้อมต์ตามโครงสร้างนี้ ระบบอ่านแปลงเป็นค่าแถบเลื่อน **ในเครื่อง** ทันที ไม่มีค่าใช้จ่าย ใช้งานออฟไลน์ได้ ผลเหมือนเดิมทุกครั้ง
>
> พฤติกรรมอ้างอิง: `reference/sgp-reference.mjs` + test `reference/sgp-reference.test.mjs` (18 เคส ผ่านทั้งหมด รวม round-trip สุ่ม 500 ชุด) · คำศัพท์: `seed/sgp-vocabulary.json`

## 1. หลักการออกแบบ

| หลักการ | เหตุผล |
|---|---|
| อ่านง่ายเหมือนโน้ตของช่างภาพ | เขียนด้วยมือได้โดยไม่ต้องจำตัวเลข: `เงา: ยก ปานกลาง` |
| ตัวเลขชนะคำเสมอ | เขียน `เงา: ยก ปานกลาง (+30)` ได้ทั้งความหมายที่อ่านออกและค่าที่แม่นยำ |
| ทนต่อความผิดพลาด | บรรทัดที่อ่านไม่ออกเป็น **คำเตือนพร้อมเลขบรรทัด** ไม่ทำให้ทั้งไฟล์ล้มเหลว |
| ไปกลับได้ไม่เสียข้อมูล | `serialize → parse` ได้ค่าเดิมทุกพารามิเตอร์ (round-trip) จึงใช้เป็นรูปแบบจัดเก็บและแบ่งปันได้ |
| คำศัพท์เป็นข้อมูล | เพิ่มคำใหม่ได้ใน `sgp-vocabulary.json` โดยไม่แก้โค้ด |
| ไทยและอังกฤษปนกันได้ | ทุกหัวข้อและคำมีชื่อทั้งสองภาษา |

## 2. โครงสร้างไฟล์

- ไฟล์ข้อความ UTF-8 นามสกุล `.sgp.txt` (รับ `.txt` และ `.md` ด้วย) หรือพิมพ์/วางในช่องพร้อมต์
- หนึ่งบรรทัดหนึ่งการตั้งค่า รูปแบบ `หัวข้อ: ค่า` (รับ `:` และ `：`)
- บรรทัดว่าง, บรรทัดรั้วโค้ด ```` ``` ```` (จากคำตอบที่วางมาจากแชต) และข้อความหลัง `//` ถูกข้าม; ขึ้นต้นด้วย `- `, `* `, `• ` ได้
- **บรรทัดข้อมูลกำกับ:** `# ชื่อ: …` · `# แท็ก: a, b` · `# รุ่นรูปแบบ: 1` ทั้งบรรทัดเป็นค่า จึงใช้ `//` ในชื่อได้ ตัวเขียนรวมชื่อและแท็กให้อยู่ในบรรทัดเดียวเสมอ และแทนจุลภาคในแท็กด้วยช่องว่าง
- **หัวส่วน** `[ชื่อส่วน]` ใช้จัดกลุ่มเพื่ออ่านง่าย ไม่มีผลต่อการอ่านค่า ยกเว้นสองส่วนพิเศษ:
  - `[หมายเหตุ]` / `[notes]` → เก็บเป็นข้อความ แสดงในกล่องคำอธิบาย ไม่ถูกอ่านเป็นค่า
  - `[ห้ามเปลี่ยน]` / `[preserve]` → เก็บเป็นข้อความ (เครื่องยนต์รักษาต้นฉบับอยู่แล้ว)
- ส่วนพิเศษมีผลจนถึงหัวส่วนถัดไป
- ในส่วนพิเศษ บรรทัดว่างและ `//` ถูกเก็บตามเดิม บรรทัดที่ขึ้นต้นด้วย `\` ถูกเก็บเป็นข้อความโดยตัด `\` ตัวแรกออก ตัวเขียนใช้วิธีนี้กับบรรทัดที่ขึ้นต้นด้วย `[`, `#`, ```` ``` ```` หรือ `\` เพื่อไม่ให้ถูกอ่านเป็นโครงสร้าง
- พารามิเตอร์ที่ไม่ได้เขียน = ค่าเป็นกลาง (ความเข้มรวม = 100)

## 3. ตัวอย่างเต็ม (พอร์ตเทรตเด็กสดใส)

```text
# ชื่อ: พอร์ตเทรตเด็กสดใส
# แท็ก: พอร์ตเทรต, เด็ก
# รุ่นรูปแบบ: 1

[แสง]
ความสว่าง: สว่างขึ้น เล็กน้อย (+22)
คอนทราสต์: นุ่ม นิดเดียว (-5)
ไฮไลต์: กด นิดเดียว (-15)
เงา: ยก ปานกลาง (+30)
ลดความมัว: เล็กน้อย (20)

[สี]
อุณหภูมิสี: เย็น นิดเดียว (-4)
ทินต์: ม่วงแดง นิดเดียว (+6)
แก้สีเพี้ยน: มาก (70)
ความอิ่มสี: จาง นิดเดียว (-4)
ไวบรานซ์: สด นิดเดียว (+12)
กันเหลือง: ปานกลาง (30)

[โทนเงาและไฮไลต์]
สีไฮไลต์: ชมพู นิดเดียว (330°, 8)

[ปรับรายสี]
แดง: สว่าง เพิ่ม นิดเดียว (+4)
เหลืองส้ม: อิ่ม ลด นิดเดียว (-15)
เขียว: อิ่ม ลด เล็กน้อย (-25)
ม่วง: อิ่ม เพิ่ม เล็กน้อย (+25), สว่าง เพิ่ม นิดเดียว (+10), เฉด ลด นิดเดียว (-5)

[รายละเอียด]
ความคมชัด: ปานกลาง (35)
ลดจุดรบกวน: เล็กน้อย (25)

[หมายเหตุ]
ทำไม่ได้ใน MVP: ทำฉากหลังให้เป็นกลางโดยไม่กระทบตัวเด็ก และเพิ่มความคมเฉพาะรอบดวงตา (ต้องใช้ mask เฉพาะพื้นที่)

[ห้ามเปลี่ยน]
ใบหน้า สีหน้า ทรงผม เครื่องแต่งกาย ปีกนางฟ้า ท่าทาง ฉากหลัง องค์ประกอบ ขนาดภาพ
```

เขียนสั้นแบบไม่ใส่ตัวเลขก็ได้ ระบบจะใช้ค่าตามตารางระดับ:

```text
# ชื่อ: เช้าสดใส
ความสว่าง: สว่างขึ้น เล็กน้อย
เงา: ยก ปานกลาง
อุณหภูมิ: อุ่น นิดเดียว
สีไฮไลต์: ครีม เล็กน้อย
ม่วง: อิ่ม เพิ่ม ปานกลาง
ความคม: เล็กน้อย
```

## 4. กติกาการอ่านค่า

### 4.1 ค่าเดี่ยว (scalar) — ลำดับการตัดสิน
1. **ตัวเลข:** ถ้ามีวงเล็บ ใช้ตัวเลขในวงเล็บชุดสุดท้าย ไม่เช่นนั้นใช้ตัวเลขแรกในค่า
   ตัวเลขไม่มีเครื่องหมาย + มีคำทิศลบ (เช่น `ลด 30`) → ติดลบ (พารามิเตอร์ทางเดียวใช้ข้อ 6); มีเครื่องหมายแล้วใช้ตามนั้น; บีบเข้าช่วงของพารามิเตอร์
2. **คำกลาง** (`ไม่ปรับ`, `ปิด`, `คงเดิม`, `none`, `off`) → ค่าเป็นกลาง
3. **คำพิเศษของพารามิเตอร์** เช่น `ความอิ่มสี: ขาวดำ` = −100, `ระยะหมอก: ยาว` = 70
4. **ทิศ + ระดับ:** ทิศลบเมื่อพบคำทิศลบ (ทั่วไปหรือเฉพาะพารามิเตอร์) ไม่เช่นนั้นเป็นบวก; ระดับจากตารางข้อ 5.1 ถ้ามีแต่ทิศไม่มีระดับ ใช้ `ปานกลาง` (35)
5. ไม่พบทั้งตัวเลข คำทิศ และคำระดับ → คำเตือน และไม่เปลี่ยนค่า
6. พารามิเตอร์ทางเดียว (ช่วง 0..100) เจอคำทิศลบ → 0 พร้อมคำเตือน ไม่ว่าจะมีตัวเลขหรือไม่ และรวมถึง `ความเข้มรวม` กับ `ระยะหมอก` ที่ค่าเป็นกลางไม่ใช่ 0

การจับคำ: ตัดช่องว่างและตัวพิมพ์ใหญ่เล็กออกก่อน แล้วจับ **คำที่ยาวที่สุดก่อน** และไม่ใช้ตัวอักษรซ้ำ (เช่น `มากขึ้น` ถูกจับเป็นทิศบวก ไม่ถูกจับเป็นระดับ `มาก`) จึงรองรับภาษาไทยที่ไม่เว้นวรรค

### 4.2 สีเงา / สีไฮไลต์ (ตั้งสองค่าในบรรทัดเดียว)
`สีเงา: <ชื่อสี หรือ N°> <ระดับ หรือ ตัวเลข>` → `shHue` + `shSat`
ตัวเลขที่มี `°` หรือ `องศา` = เฉดสี, ตัวเลขอื่น = ความเข้ม; `สีเงา: ไม่ปรับ` → ความเข้ม 0
องศาที่ยาวเกินจนไม่ใช่จำนวนจำกัดถูกข้าม แล้วใช้ชื่อสีแทน ถ้าไม่มีชื่อสี → คำเตือนและไม่เปลี่ยนค่า

### 4.3 ปรับรายสี (HSL)
`<ชื่อแถบสี>: <คุณสมบัติ> <ค่า>, <คุณสมบัติ> <ค่า>, …`
คุณสมบัติขึ้นต้นด้วย `อิ่ม` (saturation), `สว่าง` (luminance), `เฉด` (hue shift) แต่ละส่วนอ่านแบบข้อ 4.1 เช่น `ม่วง: อิ่ม เพิ่ม ปานกลาง, สว่างขึ้น นิดเดียว, เฉด -5`

### 4.4 คำเตือน (ไม่หยุดการอ่าน)
| สถานการณ์ | ข้อความ |
|---|---|
| ไม่มี `:` | ไม่มีเครื่องหมาย ":" — ข้ามบรรทัดนี้ |
| ไม่รู้จักหัวข้อ | ไม่รู้จักหัวข้อ "…" (UI แนะนำหัวข้อที่สะกดใกล้เคียง) |
| อ่านค่าไม่ได้ | <หัวข้อ>: ไม่พบคำบอกระดับหรือตัวเลข |
| ตั้งซ้ำ | ตั้งค่า <key> ซ้ำ (บรรทัด n) ใช้ค่าบรรทัดล่าสุด |
| ทิศลบกับค่าทางเดียว | ค่านี้ไม่มีทิศลบ ใช้ค่าต่ำสุดแทน |

## 6. การเขียนกลับ (serializer)

ใช้เมื่อผู้ใช้กด "บันทึก" หรือ "ส่งออกเป็นไฟล์พร้อมต์" หลังปรับแถบเลื่อน
- เขียนเฉพาะค่าที่ไม่เป็นกลาง จัดตามส่วน: แสง · สี · ใบไม้ · โทนเงาและไฮไลต์ · ปรับรายสี · บรรยากาศและฟิล์ม · รายละเอียด
- รูปแบบ `<ชื่อหลัก>: <คำทิศ> <คำระดับที่ใกล้ที่สุด> (<ตัวเลขจริง>)` เพื่อให้คนอ่านเข้าใจและค่าคงความแม่นยำ
- ข้อกำหนด: `parse(serialize(p)).params` เท่ากับ `p` ทุกพารามิเตอร์ และไม่มีคำเตือน

## 7. ตัวช่วยสำหรับพร้อมต์เขียนอิสระ (ไม่ใช้ API)

พร้อมต์ยาวแบบอิสระ (เช่นพร้อมต์พอร์ตเทรตภาษาอังกฤษ) แปลงเป็นโครงสร้างได้สองทาง:

1. **เขียนเองด้วยแม่แบบ:** ปุ่ม "แทรกแม่แบบ" ใส่ทุกหัวข้อพร้อมค่า `ไม่ปรับ` ให้แก้ทีละบรรทัด
2. **ให้แชต Claude ช่วยเรียบเรียง:** ปุ่ม "คัดลอกคำสั่งสำหรับแชต Claude" สร้างข้อความ = คำสั่งจาก `seed/sgp-bridge-instruction.md` + พร้อมต์อิสระของผู้ใช้ → ผู้ใช้วางในแชต Claude ที่ใช้อยู่ (claude.ai หรือแอป) → คัดลอกบล็อกคำตอบกลับมาวางในช่องพร้อมต์ → ระบบอ่านทันที
   - ไม่ต้องมี API key ใช้โควตาแชตตามแพ็กเกจของผู้ใช้
   - ผลที่วางกลับผ่านตัวอ่านเดียวกัน จึงปลอดภัยเท่าข้อความที่ผู้ใช้พิมพ์เอง
   - แอปไม่เปิดลิงก์หรือส่งข้อมูลออกเอง ผู้ใช้คัดลอก-วางด้วยตัวเองทุกครั้ง
