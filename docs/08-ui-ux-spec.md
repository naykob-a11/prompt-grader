# 08 · สเปก UI/UX

## 1. โครงหน้าจอ

```
┌─────────────────────────────────────────────────────────────────────────┐
│ แถบบน: โลโก้+ชื่อ · [เปิดภาพ] · [ส่งออก] · เมนู (ตั้งค่า, ทางลัด)          │
├──────────────┬──────────────────────────────────┬───────────────────────┤
│ คลังพร้อมต์   │ เวที (Stage)                      │ แท็บ [พร้อมต์] [แถบเลื่อน] │
│ ─ค้นหา/แท็ก   │  ภาพ + เส้นเทียบก่อน/หลัง           │  พร้อมต์: ตัวแก้ไข SGP     │
│ ─ของฉัน      │  ซูม/เลื่อน · histogram (พับได้)    │   + คำเตือนรายบรรทัด      │
│ ─ตัวอย่าง     │  แถบล่าง: ข้อมูลภาพ · โหมดเทียบ      │   [แนบ][แม่แบบ][แชต]     │
│ ─แนบ/ส่งออก  │                                  │  แถบเลื่อน: ตามกลุ่ม      │
└──────────────┴──────────────────────────────────┴───────────────────────┘
```

| ความกว้าง | การจัดวาง |
|---|---|
| ≥ 1200 px | 3 คอลัมน์: 270 px · ยืดหยุ่น · 340 px |
| 820–1199 px | เวที + ตัวแก้ไข; คลังพร้อมต์อยู่ใต้เวที |
| < 820 px | เวที (sticky ด้านบน สูง ≤ 45vh) → แท็บ "คลัง / ปรับ / พร้อมต์" |

## 2. Design tokens (ต่อยอดจากต้นแบบ)

```css
:root {
  --bg:#eef1ef; --panel:#f8faf9; --line:#d5ddda; --fg:#1b2422; --muted:#5d6b67;
  --accent:#1f7d74; --accent-ink:#fff; --accent-soft:#dcebe8; --stage:#dfe5e2; --danger:#b3412f;
  --font-display:"Anuphan", "IBM Plex Sans Thai", system-ui, sans-serif;
  --font-body:"IBM Plex Sans Thai", system-ui, sans-serif;
  --font-mono:"IBM Plex Mono", ui-monospace, monospace;
  --radius-sm:6px; --radius:8px; --radius-lg:10px;
  --space-1:4px; --space-2:8px; --space-3:12px; --space-4:16px; --space-6:24px;
}
/* ธีมมืด: --bg:#101615 --panel:#161e1c --line:#26312e --fg:#e4ebe8 --muted:#8fa09b
           --accent:#4fb3a8 --accent-ink:#071211 --accent-soft:#1c3330 --stage:#0b100f --danger:#e07a66 */
```

- สีเน้น teal มาจากเอกลักษณ์ของพรีเซ็ตแรก ใช้เฉพาะปุ่มหลัก สถานะเลือก และแถบเลื่อน
- เวทีภาพใช้พื้นเป็นกลางเสมอ (ไม่มีสีเน้นรอบภาพ) เพื่อไม่รบกวนการตัดสินสี
- ตัวเลขทั้งหมดใช้ `font-variant-numeric: tabular-nums`

## 3. ส่วนประกอบหลัก

| ส่วนประกอบ | พฤติกรรม |
|---|---|
| `ParamSlider` | ป้าย + ค่า (mono) + range; ดับเบิลคลิกป้าย = รีเซ็ต; ลูกศร = ±1, Shift+ลูกศร = ±10; จุดบอกตำแหน่งค่าเป็นกลางบนราง |
| `ParamSlider` (`kind: 'hue'`) | ราง gradient สีรุ้ง, แสดงค่าเป็นองศา, ตัวอย่างสีเล็กข้างค่า |
| `ParamGroup` | `<details>` พับได้, จุดสีบอก "กลุ่มนี้มีค่าที่ไม่เป็นกลาง", จำสถานะพับต่อผู้ใช้ |
| `CompareSlider` | ลากเส้นแบ่ง, คีย์ ←/→ เลื่อนเส้น, ป้าย "ก่อน"/"หลัง" |
| `PromptItem` | ชื่อ (ตัวหนา) + ข้อความ 2 บรรทัด; สถานะ current; เมนู ทำสำเนา/เปลี่ยนชื่อ/ลบ; ลบต้องกดยืนยันในแถว |
| `PromptEditor` | CodeMirror 6: ไฮไลต์หัวข้อ/คำระดับ/ตัวเลข/หัวส่วน, ขีดเส้นใต้บรรทัดที่มีคำเตือน + tooltip ข้อความ, autocomplete หัวข้อและคำระดับ, อ่านใหม่หลังหยุดพิมพ์ 150 ms |
| `WarningList` | รายการคำเตือนใต้ตัวแก้ไข คลิกแล้วกระโดดไปบรรทัดนั้น; "ทุกบรรทัดอ่านได้" เมื่อไม่มีคำเตือน |
| `AttachButton` | เลือกไฟล์ `.sgp.txt/.txt/.md` หลายไฟล์ได้ |
| `TemplateButton` | แทรกแม่แบบทุกหัวข้อ (ถามยืนยันในหน้าก่อนแทนข้อความเดิม) |
| `ChatBridgeDialog` | ช่องวางพร้อมต์อิสระ → ปุ่ม "คัดลอกคำสั่ง" → ขั้นตอน 1-2-3 (วางในแชต Claude → คัดลอกคำตอบ → วางในช่องพร้อมต์) แสดงข้อความคำสั่งให้เลือกคัดลอกเองได้หากคลิปบอร์ดถูกปฏิเสธ |
| `NotesPanel` | แสดง `[หมายเหตุ]` และ `[ห้ามเปลี่ยน]` เป็นข้อความธรรมดา |
| `ReferenceWindow` | ปุ่มบนแถบด้านบนเปิดหน้าต่างแยก: เลือกหรือลากภาพอ้างอิงมาวาง → วิเคราะห์ใน Worker → เห็นภาพอ้างอิงคู่กับผลบนภาพที่เปิดอยู่ ปรับชื่อ แถบเลื่อนของค่าที่จับคู่ และข้อความพร้อมต์ได้ (`DraftEditor`) → กด "บันทึกเข้าคลัง" จึงเพิ่มในคลังและใช้กับภาพหลักเป็น undo หนึ่งขั้น ปิดหน้าต่างโดยไม่บันทึกแล้วภาพหลักไม่เปลี่ยน และร่างยังอยู่จนกว่าจะปิดหน้า |
| `ErrorBoundary`, `public/boot.js` | แอปพังระหว่างทำงาน หรือ bundle โหลด/อ่านไม่ได้ → แสดงข้อความ สาเหตุ และปุ่มโหลดใหม่แทนหน้าขาว; `boot.js` เป็น ES5 นอก bundle จึงทำงานได้แม้ bundle พัง และล้าง service worker กับแคชก่อนโหลดใหม่ |
| `ExportDialog` | รูปแบบ, คุณภาพ, คงข้อมูล EXIF, ตัด GPS, ชื่อไฟล์, แถบความคืบหน้า |

## 4. ข้อความ UI (ตัวอย่าง i18n `th.json`)

| key | ข้อความ |
|---|---|
| `app.title` | เกรดสีจากพร้อมต์ |
| `stage.dropHint` | ลากภาพมาวาง วางด้วย Ctrl+V หรือกด “เปิดภาพ” |
| `stage.sample` | ภาพตัวอย่าง |
| `library.mine` | พร้อมต์ของฉัน |
| `library.builtin` | ตัวอย่างในตัว |
| `library.empty` | ยังไม่มีพร้อมต์ของคุณ กด “+ พร้อมต์ใหม่” หรือทำสำเนาจากตัวอย่าง |
| `editor.attach` | แนบไฟล์พร้อมต์ |
| `editor.template` | แทรกแม่แบบ |
| `editor.allRead` | ทุกบรรทัดอ่านได้ |
| `editor.warnings` | {count} บรรทัดที่อ่านไม่ได้ |
| `editor.suggest` | หมายถึง “{suggestion}” หรือเปล่า |
| `bridge.title` | ให้แชต Claude ช่วยเรียบเรียงพร้อมต์ |
| `bridge.steps` | 1. คัดลอกคำสั่ง 2. วางในแชต Claude ที่คุณใช้ 3. คัดลอกคำตอบกลับมาวางในช่องพร้อมต์ |
| `bridge.copy` | คัดลอกคำสั่ง |
| `bridge.copied` | คัดลอกแล้ว นำไปวางในแชต Claude ได้เลย |
| `export.prompt` | ส่งออกเป็นไฟล์พร้อมต์ (.sgp.txt) |
| `export.button` | ส่งออกภาพความละเอียดเต็ม |
| `export.progress` | กำลังประมวลผล {percent}% |
| `error.notImage` | ไฟล์นี้ไม่ใช่ภาพ เลือกไฟล์ JPG, PNG หรือ WebP |
| `error.notText` | ไฟล์นี้ไม่ใช่ข้อความ UTF-8 บันทึกไฟล์ใหม่เป็น UTF-8 แล้วแนบอีกครั้ง |
| `error.tooLarge` | ไฟล์พร้อมต์ใหญ่เกิน 64 KB |

หลักการเขียน: ประโยคสั้น ภาษาสุภาพไม่เป็นทางการเกินไป ปุ่มบอกการกระทำตรง ๆ ข้อความผิดพลาดบอกสาเหตุและวิธีแก้ ไม่ขอโทษ

## 6. การเข้าถึง (Accessibility)

- ทุกแถบเลื่อนมี `<label for>` และ `aria-valuetext` (เช่น "บวก 25")
- focus มองเห็นชัด (outline 2px สี accent)
- ปุ่มสถานะใช้ `aria-pressed`; ข้อความสถานะใช้ `role="status"`
- รองรับ `prefers-reduced-motion`
- contrast ข้อความ ≥ 4.5:1 ทั้งสองธีม
