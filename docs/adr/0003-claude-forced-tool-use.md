# ADR 0003 · เรียก Claude ผ่าน API ฝั่งเซิร์ฟเวอร์ด้วย forced tool use

- **สถานะ:** ~~ยอมรับ~~ → **ถูกแทนที่โดย ADR 0005** · 2026-11-02
- **บริบท:** ต้นแบบเรียก Claude จากหน้า artifact ซึ่งใช้ไม่ได้เมื่อเป็นเว็บอิสระ และ API key ห้ามอยู่ในเบราว์เซอร์
- **การตัดสินใจ:** `apps/api` (Hono) เรียก Messages API ด้วย tool เดียว `set_grading_params` ที่ `input_schema` สร้างจาก parameter schema และบังคับด้วย `tool_choice`; ตรวจผลด้วย zod + clamp
- **ผลที่ตามมา:** (+) ได้ JSON ตรงสเปกเสมอ, schema เปลี่ยน → tool เปลี่ยนตาม (−) ต้องมีเซิร์ฟเวอร์และดูแลค่าใช้จ่าย/rate limit; การแปลงพร้อมต์ใช้ออฟไลน์ไม่ได้
