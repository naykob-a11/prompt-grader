# ADR 0004 · จัดเก็บคลังพร้อมต์แบบ local-first ด้วย IndexedDB

- **สถานะ:** ยอมรับ · 2026-11-02
- **บริบท:** ผู้ใช้ต้องการเพิ่มพร้อมต์เองได้ไม่จำกัด ใช้งานได้โดยไม่ต้องสมัครบัญชี และแบ่งปันกับเพื่อนร่วมงานได้
- **การตัดสินใจ:** เก็บใน IndexedDB (Dexie), แบ่งปันด้วยไฟล์ JSON, ซิงก์คลาวด์เป็นงานต่อยอด (roadmap R6)
- **ผลที่ตามมา:** (+) ไม่มีต้นทุนเซิร์ฟเวอร์ฐานข้อมูล, ออฟไลน์ได้, ความเป็นส่วนตัวสูง (−) ล้างข้อมูลเบราว์เซอร์ = คลังหาย → UI ต้องชวนส่งออกสำรองเป็นระยะ
