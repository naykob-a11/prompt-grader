# ADR 0002 · WebGL2 เป็นเครื่องยนต์หลัก, CPU เป็นอ้างอิงและ fallback

- **สถานะ:** ยอมรับ · 2026-11-02
- **บริบท:** ต้นแบบประมวลผลด้วย JavaScript บน CPU ซึ่งช้าเมื่อพรีวิวใหญ่และเมื่อส่งออกภาพ 24–48 MP
- **การตัดสินใจ:** พรีวิวและส่งออกด้วย WebGL2 shader; เก็บ CPU implementation ไว้เป็นการคำนวณอ้างอิงสำหรับ test และ fallback ใน Web Worker
- **ทางเลือกที่พิจารณา:** WebGPU (ยังรองรับไม่ทั่วถึงทุกเบราว์เซอร์มือถือ — ทบทวนใหม่ภายหลัง), WASM SIMD (เร็วกว่า JS แต่ยังช้ากว่า GPU)
- **ผลที่ตามมา:** ต้องดูแลสองโค้ดเบสให้ตรงกัน → parity test เป็นข้อบังคับ (skill `grading-engine`)
