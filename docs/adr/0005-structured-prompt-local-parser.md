# ADR 0005 · พร้อมต์แบบโครงสร้าง (SGP) อ่านในเครื่องแทนการเรียก API

- **สถานะ:** ยอมรับ · 2026-11-02 · แทนที่ ADR 0003
- **บริบท:** การแปลงพร้อมต์ด้วย Claude API มีค่าใช้จ่ายทุกครั้งที่เรียก ต้องมีเซิร์ฟเวอร์เก็บ API key และใช้งานออฟไลน์ไม่ได้ ผู้ใช้ต้องการแนบพร้อมต์ตามโครงสร้างที่กำหนดแทน
- **การตัดสินใจ:**
  1. กำหนดรูปแบบข้อความ **Structured Grading Prompt (SGP)**: `หัวข้อ: ทิศ ระดับ (ตัวเลข)` คำศัพท์อยู่ในไฟล์ข้อมูล `seed/sgp-vocabulary.json`
  2. ตัวอ่าน/ตัวเขียนเป็น pure TypeScript ใน `packages/engine/src/sgp/` ทำงานในเบราว์เซอร์
  3. พร้อมต์เขียนอิสระ: แอปสร้าง "คำสั่งสำหรับแชต Claude" ให้ผู้ใช้คัดลอกไปวางในแชตที่ใช้อยู่ แล้ววางคำตอบกลับ — ไม่มีการเรียกเครือข่ายจากแอป
  4. ตัดแพ็กเกจ `apps/api` ออก แอปเป็น static site
- **ทางเลือกที่พิจารณา:** (ก) คง API ไว้ — ตัดเพราะค่าใช้จ่ายและความซับซ้อน (ข) โมเดลภาษาในเบราว์เซอร์ (WebGPU) — ไฟล์โมเดลใหญ่หลายร้อย MB และคุณภาพภาษาไทยไม่แน่นอน เก็บเป็น roadmap R0 (ค) JSON ล้วน — คนอ่านและเขียนด้วยมือยาก
- **ผลที่ตามมา:** (+) ฟรี, ออฟไลน์, ผลทำซ้ำได้, ไม่มีความลับ, โฮสต์ฟรี, ผู้ใช้แก้พร้อมต์ด้วยมือได้, แบ่งปันเป็นไฟล์ข้อความ (−) พร้อมต์อิสระต้องผ่านขั้นคัดลอก-วางกับแชต; คำที่ไม่อยู่ในคำศัพท์อ่านไม่ได้ (บรรเทาด้วยคำเตือนรายบรรทัด, คำแนะนำการสะกด, และ `/add-vocabulary`)
