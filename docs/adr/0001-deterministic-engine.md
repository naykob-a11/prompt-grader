# ADR 0001 · ใช้เครื่องยนต์เกรดสีแบบ deterministic แทนโมเดลสร้างภาพ

- **สถานะ:** ยอมรับ · 2026-11-02
- **บริบท:** พร้อมต์ของผู้ใช้ (เช่น พอร์ตเทรตเด็ก) ย้ำว่าห้ามเปลี่ยนใบหน้า ท่าทาง วัตถุ และองค์ประกอบ โมเดลสร้างภาพ (image-to-image) ไม่รับประกันข้อนี้และผลไม่คงที่
- **การตัดสินใจ:** ปรับภาพด้วยสูตรคณิตศาสตร์ต่อพิกเซล (+ ฟิลเตอร์ 3×3) ที่ควบคุมด้วยพารามิเตอร์ตัวเลข ใช้ Claude เฉพาะการตีความพร้อมต์เป็นพารามิเตอร์
- **ผลที่ตามมา:** (+) รักษาต้นฉบับโดยโครงสร้าง, ทำซ้ำได้, แก้ต่อได้, ประมวลผลในเครื่อง (−) ทำการแก้เฉพาะจุดไม่ได้จนกว่าจะมี mask (roadmap R3), ทำเอฟเฟกต์ที่ต้องสร้างเนื้อหาใหม่ไม่ได้
