# 11 · ความปลอดภัยและความเป็นส่วนตัว

## 1. ข้อมูลที่ระบบแตะ

| ข้อมูล | อยู่ที่ไหน | ออกจากเครื่องผู้ใช้หรือไม่ |
|---|---|---|
| ภาพต้นฉบับ/ภาพส่งออก | หน่วยความจำเบราว์เซอร์ | **ไม่** |
| ข้อความพร้อมต์, คลังพร้อมต์ | IndexedDB | **ไม่** (ยกเว้นผู้ใช้ส่งออกไฟล์เอง) |
| คำสั่งสำหรับแชต Claude | คลิปบอร์ด | เฉพาะเมื่อผู้ใช้กดคัดลอกแล้ววางเองในแชต — แอปไม่ส่งเอง |
| EXIF (รวม GPS) | ในไฟล์ภาพ | คัดลอกลงไฟล์ส่งออกตามตัวเลือก; ตัด GPS เป็นค่าเริ่มต้น |

แอปไม่มีเซิร์ฟเวอร์และไม่มีความลับ (API key, token) จึงไม่มีจุดรั่วไหลฝั่งเซิร์ฟเวอร์

ภาพบุคคล โดยเฉพาะภาพเด็ก เป็นข้อมูลอ่อนไหว: คำสั่งสำหรับแชตมีเฉพาะข้อความพร้อมต์ **ไม่แนบภาพ** และหน้าต่างคำสั่งบอกผู้ใช้ชัดว่าข้อความใดจะถูกคัดลอก

## 2. ข้อมูลที่ไม่น่าเชื่อถือ

ไฟล์ที่แนบ, ข้อความที่วาง (รวมคำตอบจากแชต) และไฟล์คลังที่นำเข้า ถือว่าไม่น่าเชื่อถือ
- ตัวอ่าน SGP ให้ผลได้เพียง **ตัวเลขในช่วงของ schema** + ข้อความชื่อ/แท็ก/หมายเหตุ ไม่มีทางให้ข้อความไปสั่งการระบบได้
- จำกัดขนาด: ไฟล์พร้อมต์ 64 KB / 2,000 บรรทัด, คลัง 5 MB / 1,000 รายการ, ชื่อ 80 ตัวอักษร, แท็ก 20 รายการ
- ตัวอ่านต้องไม่ throw กับอินพุตใด ๆ (fuzz test) และทำงานเป็นเวลาเชิงเส้น — ห้ามใช้ regex ที่ backtrack แบบทวีคูณ
- ชื่อ หมายเหตุ และคำเตือนแสดงด้วย `textContent` หรือ React text node เท่านั้น ห้าม `dangerouslySetInnerHTML` และห้าม render เป็น Markdown/HTML
- ชื่อไฟล์ส่งออกตัดอักขระต้องห้ามของระบบไฟล์และ path separator

## 3. Supply chain และการโฮสต์

- ล็อกเวอร์ชันด้วย `pnpm-lock.yaml`; Renovate/Dependabot สำหรับอัปเดต
- bundle ทุกอย่าง ไม่โหลดสคริปต์จาก CDN, ฟอนต์ self-host
- CSP: `default-src 'self'; img-src 'self' blob: data:; connect-src 'self'; style-src 'self'; font-src 'self'; worker-src 'self' blob:; base-uri 'self'; frame-ancestors 'none'`
- `connect-src 'self'` ทำให้แม้มีโค้ดผิดพลาดก็ส่งข้อมูลออกนอก origin ไม่ได้ (e2e ตรวจซ้ำ)
- `tests/e2e/csp.spec.ts` ใส่นโยบายนี้ให้ build จริงแล้วตรวจว่าไม่มีสิ่งใดถูกบล็อก ตัวแก้ไขพร้อมต์อยู่ใน Shadow DOM เพราะ CodeMirror จะใช้ constructed stylesheet แทนแท็ก `<style>` จึงไม่ต้องเพิ่ม `'unsafe-inline'`
